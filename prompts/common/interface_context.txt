The JSON object below contains only declarations recognized in the main model source. Each declaration has a name, a kind (set, parameter, variable, or unknown), its original source text, and a one-based starting line in the supplied model. Types, symbolic index domains, defaults, and definitions remain in the original declaration text. An unknown kind means the declaration cannot be reliably classified.
Recognition is conservative and may omit unsupported or ambiguous declarations. An empty list does not establish that the model has no declarations. Use the complete main model source as the authority; do not infer missing declarations or values from omissions. No external instance data or statistics are included. Values already embedded in model declarations remain unchanged. All custom definitions are expected in the main file; language-specific standard libraries remain subject to the requirements above.
